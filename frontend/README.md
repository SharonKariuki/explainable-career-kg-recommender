# Frontend (React + Vite)

Sprint 1 scaffold only. This is the unmodified Vite React template apart from
the page title. No screens, components or routing have been added yet; those
arrive in Sprint 5.

## Commands

Run from this `frontend/` folder (Node.js 20 or newer; developed on Node 22.14):

```bash
npm install        # install dependencies from package-lock.json
npm run dev        # dev server on http://localhost:5173
npm run build      # production build into frontend/dist/
npm run preview    # serve the production build locally
npm run lint       # oxlint
```

`node_modules/` and `dist/` are gitignored.
